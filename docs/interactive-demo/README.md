# Historical prepared synthetic walkthrough

This repository page is the original prepared walkthrough. It swaps fictional records and explanations in the browser; it does not recalculate a pair or call the Python matcher. Its threshold control changes only an explanatory annotation. For the newer public demo, which calculates an edited pair with a separate simplified JavaScript demonstration, visit the [hosted Entity Resolution demo](https://ardianmehaj.dev/projects/entity-resolution-workbench/). The public calculation is not in parity with this repository's Python engine.

Open index.html directly, or from this repository run:

```sh
python -m http.server 8080 --bind 127.0.0.1 --directory docs/interactive-demo
```

Then open http://127.0.0.1:8080/. No server engine, account, payment, API call or installation is required for this frontend. The fictional fixtures and their limits are documented in [DEMO_DATA.md](DEMO_DATA.md). Reset restores the local controls.
