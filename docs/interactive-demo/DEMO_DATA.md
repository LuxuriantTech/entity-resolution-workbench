# Interactive demonstration data

All values rendered by `demo.js` are prepared fictional examples. The browser stores no result and makes no network request.

| Page | Fixture choices | What the browser does | What it does not do |
| --- | --- | --- | --- |
| ToolCall Replay | approved address lookup; risky directory update | filters prepared trace events and explains the prepared verdict | runs tools, agents, models, or network requests |
| Entity Resolution Workbench | Harbor Desk Lamp; Lumen Task Chair; Stoneware Mug | swaps prepared records, explanations, and similarities; threshold changes an explanatory label | runs the local matcher or turns similarities into probabilities |
| PostgreSQL Migration Rehearsal | five migration stages for six fictional invoices | guides a prepared report | starts PostgreSQL, Docker, or a migration |
| API Contract Guard | removed operation; required parameter; required response property | swaps hand-authored illustrative reports for supported categories | runs the TypeScript comparator or covers all OpenAPI |
| EvidenceDesk | supported answer; abstention; frozen v7 limitation | shows prepared answer and source passages | queries the prototype or creates a new model-quality evaluation |

The PMR preview remains prepared because its frozen local runtime image is currently blocked by an identity check. EvidenceDesk's frozen v7 `HONEST_NEGATIVE` remains unchanged.

The Harbor Desk Lamp REVIEW reference is derived from the preserved local walkthrough capture in `assets/entity-desktop-results.png`; the browser does not recalculate it. Lumen Task Chair and Stoneware Mug are hand-authored synthetic illustrations. Their labels and rounded similarities are explanatory values, not recorded matcher output. API Contract Guard's three browser reports are likewise hand-authored illustrations of documented categories, not CLI output.
